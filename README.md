# Escenario Multiagente | Margaret Hamilton y Profe Nexo

Set 3D con cámaras de cine donde conversan agentes de voz de ElevenLabs (Proyecto DIA, Didáctica con IA).
Tiene dos modos: **En vivo** (charlás por micrófono y les pasás la palabra nombrándolos o tocando su nombre) y **Guion** (actúan un guion con las voces de ElevenLabs o la del dispositivo; la página graba un video 1920×1080).

## Publicar
- **GitHub Pages:** creá un repositorio público nuevo (por ejemplo `escenario-multiagente`), *Add file → Upload files* con `index.html`, y después *Settings → Pages → Branch: main / (root) → Save*.
- **Netlify:** arrastrá la carpeta a app.netlify.com/drop.

## Importante
- En vivo y las voces de ElevenLabs solo andan con la página **publicada con https**, no abriendo el archivo con doble clic.
- Cada turno gasta créditos de ElevenLabs.
- La clave de API se crea en ElevenLabs → Developers → API Keys. No se comparte con nadie.
- En vivo habla un agente por vez; al cambiar de personaje hay un segundo de espera.
- Margaret Hamilton y Profe Nexo son recreaciones/personajes de IA. Si lo usás con chicos (Mele es para chicos), conviene activar los filtros de contenido de ElevenLabs en todos los agentes del elenco.
